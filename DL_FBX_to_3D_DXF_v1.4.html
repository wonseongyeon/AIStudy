왼쪽과 오른쪽 목록 클릭 시 해당 객체를 확대합니다. Ctrl+클릭으로 추가하거나 해제합니다. 오른쪽 목록을 일반 클릭하면 기존 다중 선택은 유지됩니다.

범위 선택은 깊이 전체를 대상으로 하므로 가려진 객체도 포함합니다. 선택된 객체는 청록색으로 표시됩니다. Esc: 선택 해제 / F: 선택 전체 확대.

선택 객체 JSON은 선택한 객체의 이름·계층·정점·면·선·속성만 담습니다. DXF 원문 포함을 켜면 선택 범위에 해당하는 DXF만 포함합니다.

DXF: AutoCAD R12 (AC1009), 3DFACE / LINE. 색상은 CAD 인덱스 색상으로 근사합니다. 원본 FBX 좌표와 축을 유지하며 단위는 추정하지 않습니다. CAD에서 ZOOM Extents로 확인하세요.

CAD 솔리드, FBX에 없는 BIM 속성은 복원되지 않습니다. 텍스처·애니메이션·SkinnedMesh·Point는 지원하지 않습니다. 건너뛴 형상은 JSON 경고에 기록합니다.

파일은 서버로 전송하지 않습니다. 대형 FBX는 읽는 동안 일시적으로 응답이 느릴 수 있습니다.
